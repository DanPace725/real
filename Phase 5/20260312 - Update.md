**Date:** March 12, 2026
**Context:** This document captures where Phase 5 stands after the first experimental runs, for continuity across sessions and AI instances.

## What Phase 5 Is

Phase 5 applies REAL as an **endogenous slow layer operating inside LLM inference**, not as an external evaluator. The fast layer is token-by-token generation. The slow layer (REAL) observes activation statistics across ~20-token generation segments, evaluates coherence across six dimensions, and applies bounded tilt interventions (temperature adjustment, prefix injection) to influence the next segment.

The core hypothesis: competing optimization constraints during inference produce measurable distributional signatures that an endogenous coherence algorithm can identify and respond to — without an external reward signal.

The Phase 4 `real_core/` engine is reused unchanged. Phase 5 adds the `real_inference/` domain adapter: `hooks.py`, `adapter.py`, `coherence.py`, `live.py`, `m2.py`.

## What Has Been Run

### M0 — Observational Experiment (Complete)

**Question:** Do competing-constraint prompts produce different entropy profiles than single-objective prompts?

**Setup:** 12 matched prompt pairs (same topic, one clear-objective version and one contradictory-reconciliation version). Final-layer logit entropy and activation statistics measured per generated token. Statistics: Cliff's delta, bootstrap 95% CI, permutation p-value.

**Results across three model scales:**

| Model | Entropy mean diff | Cliff's δ | p-value | Hidden state delta | p-value |
|---|---|---|---|---|---|
| Qwen3-0.6B (N=12) | -0.025 | 0.056 | 0.562 | -27.6 | 0.904 |
| Pythia-1B (N=12) | +0.132 | 0.264 | 0.230 | +0.59 | 0.386 |
| **Pythia-2.8B (N=12)** | **+0.178** | **0.319** | **0.047** | **+8.24** | **0.008** |

The entropy mean signal strengthens monotonically with model scale. At Pythia-2.8B, the primary metric (token entropy mean) crosses conventional significance (p=0.047) and hidden state delta is strongly significant (p=0.008, CI excludes zero). The pre-registered acceptance criterion was not formally met (entropy CI grazes zero by ~0.002), but directional support is established.

Full report: `experiments/m0/M0_report.md`

### M2 — Minimal REAL Loop (First run complete)

**Question:** Does the REAL loop run against live inference, and does GCO state vary?

**Setup:** Pythia-1B, competing prompt `cp_001` (remote work contradiction), 10 cycles, 24 tokens per segment, 240 tokens total, interventions enabled.

**Results:**

| Summary stat | Value |
|---|---|
| Cycles | 10 |
| Mean coherence | 0.463 |
| GCO states observed | CRITICAL (2), DEGRADED (8) |
| GCO variation (M2 success criterion) | **true** |
| Interventions fired | `adjust_temperature_up` at cycles 7 and 10 |
| Temperature trajectory | 0.8 → 0.9 → 1.0 |

**The loop works.** REAL completed 10 cycles, the CFAR selector fired real interventions (not just `observe`/`rest`), temperature changed as a result, and GCO state varied. The coherence scores are low (mostly DEGRADED/CRITICAL) because the coherence function has not been calibrated against Pythia-1B's activation baseline — that is M3's purpose.

## What's Next

**M3 — Coherence Calibration**

The coherence function (`InferenceCoherenceModel`) needs its dimension thresholds calibrated against actual activation baseline behavior. The Phase 2 pattern: run multiple sessions on non-competing prompts to establish what "normal" looks like in each dimension, then set scoring thresholds so the six dimensions produce meaningful variance in the target operating range.

Without calibration, the CFAR selector has accurate information about *relative* coherence change (delta), but absolute GCO status is unreliable. The temperature interventions are firing, but the question of whether they're producing *coherence recovery* can't be answered yet.

Concrete M3 steps:
1. Run 5–10 sessions on non-competing prompts (use `nc_*` prompts from `prompts_m0.json`), log all six dimension scores
2. Set the viability floor per dimension to the 20th percentile of baseline
3. Confirm DEGRADED/PARTIAL/STABLE states appear with appropriate frequency on competing vs. non-competing prompts
4. Re-run M2 with calibrated coherence function and compare GCO distribution

## Key Design Decisions (for new AI instances)

- **No external quality signal.** The coherence function reads only observable structural properties of inference (logit entropy, attention distributions, hidden state deltas). Adding any external quality judgment degenerates REAL into RLHF with extra steps.
- **Tilt coupling only.** Temperature delta is bounded to ±0.1 per cycle, absolute range [0.4, 1.2], 3-cycle cooldown. This keeps interventions in tilt territory (changing traversal dynamics, not landscape geometry).
- **One REAL cycle = one generation segment (~20–24 tokens).** This gives genuine speed differential between the slow layer (REAL, across segments) and the fast layer (token generation).
- **Epistemic asymmetry is a feature.** REAL observes computed statistics over hidden states, not the full activation tensors. This lossiness prevents REAL from gaming its own coherence function.
